# Nástroje pro OFN slovníky
Python skripty pro různé úkony spojené s prací s [OFN slovníky](https://ofn.gov.cz/slovníky/).
Front-end je navržen pro systém Windows. Pro instalaci a spuštění aplikace slouží install_and_run.bat.

> [!IMPORTANT]
> Nástroje jsou aktuálně ve vývoji a nejsou určené pro široké použití.
